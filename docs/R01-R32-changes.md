## 修改的代码

- kyc_poc.py：仅补source_data副本，保留原始字段，不改party1/party2。
- customer_ontology.py：新增本地schema、关系、证据、筛查、批准绑定和report_payload构建。
- policy_engine.py：准备阶段调用新检查，格式化阶段增加report_payload；原RF／FA／SG规则函数保留。
- workflow_graph.py／appetite.py：传递规则包版本以使用同一准备函数，完整图流程顺序不变。
- database_io.py／customer_export.py：新增无数据库连接的交接接口与导出工具。
- schemas/：新增输入约束、输出契约、支持工作簿hash清单。
- tests/test_customer_contract.py：新增错误证据、日期、旧批准、筛查、图及SQL关联测试。
- 原图／批处理比较测试仅额外排除每次运行本就不同的run_id和运行时间，业务结果继续逐字段比较。

## 没有修改

Safeguards候选、适用性、完成判断和原valid_approval函数保持原文；在新模式添加的是外层资料与审批绑定检查。原始工作簿、174例静态数据及party1/party2名称不修改。
